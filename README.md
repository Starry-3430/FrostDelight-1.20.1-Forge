## 简介

冰言蜜语（Frost_Delight）是一个适用于 Minecraft Java 1.20.1 的食品类 Mod。此 Mod 为 Minecraft 添加一套完整的冰淇淋与冷饮制作系统，从简单的原材料开始，制作各种冰棒、冰淇淋以及其他甜品。

🚧请注意：目前 Mod 仍处于早期开发阶段，部分内容可能会发生变化。

---

## 当前计划内容

### 🍦 新机器！

通过新的机器制作冰淇淋：

* 冰淇淋机（Ice Cream Machine）
* 搅拌机（Mixer）
* 冷冻机（Freezing Machine）

玩家可以制作基础材料，并进一步加工成不同口味的甜品。

---

### 🍧 冰棒与冰淇淋

计划加入：

* 多种口味冰棒
* 多种口味冰淇淋
* 可放置的冰淇淋方块
* 不同甜品带来的特殊效果

冰棒和冰淇淋会使用不同的容器进行制作，目前提供：

* 冰淇淋碗
* 冰棒模具（由冰棒套 + 冰棒棍合成）
* 未来会提供更多容器！

不同的容器会影响最终制作出的甜品类型。

---

### 🥛 基础材料（alpha版本）

初期将优先使用 Minecraft 原版已有资源：

* 牛奶
* 糖
* 可可豆
* 蜂蜜
* 水果类作物

同时加入一些加工材料：

* 奶油（Cream）
* 黄油（Butter）
* 香草香精（Vanilla Flavoring）
* 糖浆（Sugar Syrup）

---

### 🔎 未来计划（beta及以后）

以下内容将在后续版本考虑加入：

* 更多冰淇淋口味
* 更多冷饮（奶昔、刨冰等）
* 甜品店装饰方块
* 自动化生产设备
* 与其他食物 Mod 的联动！
